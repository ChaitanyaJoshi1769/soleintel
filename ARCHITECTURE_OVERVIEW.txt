================================================================================
🏗️  ARCHITECTURE PATTERNS
================================================================================

LAYERED ARCHITECTURE (Separation of Concerns)
  Routes → Middleware → Controllers → Services → ORM → Database

MONOREPO WITH TURBOREPO
  Root → Apps → Packages → Shared Types
  Parallel builds with dependency tracking

STATE MANAGEMENT (Frontend)
  Zustand → Local State → Persistence

TESTING STRATEGY
  Vitest → Unit + Integration → CI Validation

ERROR HANDLING
  Try/Catch → Zod Validation → Typed Errors

================================================================================
🔗 DATA FLOW
================================================================================

1. PRODUCT DETECTION
   Chrome Extension → Content Script → ProductDetector
   ↓
   Parse (JSON-LD, OG, DOM) → Service Worker
   ↓
   Send to API → Store in Zustand

2. PRICE COMPARISON
   Popup UI → Service Worker → API Request
   ↓
   API → Database → Retailers Listings
   ↓
   Return → Popup Display

3. AI INSIGHTS
   Product Context → AIEngine → GPT-4
   ↓
   Parse Response → Store Insights
   ↓
   Display in UI

4. MANUFACTURER DETECTION
   Product → Matching Engine → Source Search
   ↓
   Scraper Queue → Alibaba/AliExpress/1688
   ↓
   Match & Score → Store Results
