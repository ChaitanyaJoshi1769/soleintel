# Customer Acquisition Playbook
## Growth Strategy & Tactics for SOLEINTEL (May 2026+)
**Owner:** Marketing Lead / Growth Lead  
**Created:** May 14, 2026  
**Applies to:** Launch (May 20) and ongoing growth

---

## Overview

This playbook outlines how SOLEINTEL acquires and retains customers. It covers:
- Customer acquisition channels
- Cost per user by channel
- Retention and lifetime value
- Growth targets by phase
- Tactical campaigns

**Core metric:** Cost per acquisition (CAC) vs Lifetime value (LTV)
- Target ratio: LTV:CAC >3:1 (we make $3 per $1 spent)

## Part 2: Acquisition Channels

### Channel 1: Organic Social Media
**What it is:** Content, engagement, community building  
**Why it works:** Free, authentic, word-of-mouth

**Platform breakdown:**

**TikTok (Primary - Shoe enthusiasts)**
- Best for: Short-form videos, shoe reviews, trends
- Audience: 18-30 year olds, trend-focused
- CAC: $0 (organic)
- Volume: 1,000-5,000 views per post
- Conversion: 2-5% (high intent)

**Content strategy:**
```
Weekly posting plan:
- Mon: New shoe discovery video (5 best new shoes this week)
- Wed: Size comparison (Nike vs Adidas fit)
- Fri: Customer testimonial (unboxing + fit feedback)
- Weekend: Trend-jacking (use trending sounds/formats)

Hashtags:
#ShoesOnTok, #ShoeFit, #ShoeReview, #AirMax, #Nike, #Adidas, etc.

Engagement:
- Respond to all comments within 1 hour
- Like/comment on shoe-related content
- Create duets/stitches with followers
```

**Instagram (Secondary - Lifestyle)**
- Best for: High-quality shoe photos, lifestyle
- Audience: 20-35 year olds, style-focused
- CAC: $0 (organic)
- Volume: 500-2,000 likes per post
- Conversion: 1-2%

**Content strategy:**
```
Weekly posting plan:
- Mon: Feature shoe (product details + styling)
- Wed: Customer spotlights (user reviews/photos)
- Fri: Brand partnership (collab posts)
- Stories: Daily behind-the-scenes, polls, Q&A

Hashtags:
#SneakerHead, #ShoeStyle, #SneakerCulture, etc.

Engagement:
- Respond to DMs within 2 hours
- Follow similar accounts, engage with them
- Partner with micro-influencers (10K-100K followers)
```

**Twitter/X (Tertiary - Conversation)**
- Best for: News, trends, quick takes
- Audience: 25-40 year olds, tech/shoe nerds
- CAC: $0 (organic)
- Volume: 100-500 likes per tweet
- Conversion: <1%

**Content strategy:**
```
Daily posting plan:
- News: React to shoe releases, brand news
- Tips: Quick sizing tips, shoe care
- Community: Retweet user reviews, celebrate wins
- Trends: Jump on relevant trends early

Example tweets:
"Nike just dropped the new Air Max. Here's how the size compares 
to last year's model using real data. 📊 #ShoePit"
```

### Channel 2: Influencer Partnerships
**What it is:** Paying creators to feature your app  
**Why it works:** Trusted voices, targeted audience

**Influencer strategy:**

**Tier 1: Mega influencers (1M+ followers)**
- Cost: $5K-20K per post
- Reach: 500K-2M impressions
- CAC: $2-5 per user
- Best for: Awareness, launch campaigns
- Risk: High cost, lower engagement %

**Example partnerships:**
```
Partner with shoe reviewers with 1M+ followers
- Unbox SOLEINTEL (video walkthrough)
- Try shoe recommendations (test predictions)
- Share honest review
```

**Tier 2: Macro influencers (100K-1M followers)**
- Cost: $500-5K per post
- Reach: 50K-500K impressions
- CAC: $1-2 per user
- Best for: Growth phase, conversions
- Risk: Medium cost, better engagement

**Example partnerships:**
```
Partner with lifestyle/fashion creators
- Feature fit predictions (solve real problem)
- Show community reviews (build trust)
- Use promo code (track conversions)
```

**Tier 3: Micro influencers (10K-100K followers)**
- Cost: $100-500 per post
- Reach: 5K-50K impressions
- CAC: $0.50-1 per user
- Best for: Efficiency, authenticity
- Benefit: High engagement %, loyal followers

**Example partnerships:**
```
Partner with local style/shoe communities
- Authentic reviews (they actually try the app)
- Engaged audience (niche, not mass)
- Long-term relationships (ongoing posts vs one-off)
```

**Influencer outreach:**

```
TEMPLATE PITCH:

Subject: Collab with SOLEINTEL - [Influencer name]

Hi [Name],

Love your shoe content! We're launching SOLEINTEL, an app that
uses ML to predict shoe fit (ending the return problem).

Would you be interested in:
- Early access to the app
- Feature review to your [followers count] followers
- $[amount] payment + free shoes for your community

Your audience seems perfect - people who care about getting 
the right fit. Let me know if interested!

[Your name]
```

**Tracking influencer performance:**

```
For each partnership:
- Unique promo code or link
- Track: clicks, installs, purchases
- CAC: Cost / (installs × conversion rate)
- ROI: (Revenue - cost) / cost

Example:
Cost: $1,000
Clicks: 5,000 (CTR: 10%)
Installs: 500 (conversion: 10%)
Purchases: 150 (30% conversion)
Revenue: $3,000 (at $20 AOV)
ROI: ($3,000 - $1,000) / $1,000 = 200% return
```

## Part 3: Customer Lifetime Value (LTV)

### Calculate Your LTV

**Formula:**
```
LTV = (Avg order value × Purchase frequency × Customer lifetime)
      - Cost of service
      
Example:
- Avg order: $60
- Purchase frequency: 1x per month
- Lifetime: 24 months (2 years)
- Service cost: $2/month
  
LTV = ($60 × 12 × 2) - ($2 × 24)
LTV = $1,440 - $48
LTV = $1,392 per customer
```

### Improve LTV

**Strategy 1: Increase average order value**
```
Tactics:
- Offer premium shoe brands ($200+)
- Bundle deals (buy 2, save 10%)
- Upsell accessories (socks, insoles)
- Recommend premium shoes in search
```

**Strategy 2: Increase purchase frequency**
```
Tactics:
- Push notifications (new drops, deals)
- Seasonal campaigns (summer, winter styles)
- Loyalty program (earn points per purchase)
- Style recommendations (wearing out? Time to replace)
```

**Strategy 3: Extend customer lifetime**
```
Tactics:
- Build community (reviews, forums)
- Reward loyalty (discounts for repeat customers)
- Keep app fresh (new features, engagement)
- Excellent support (fix issues fast)
```

### LTV by Cohort

**Track LTV by when users signed up:**

```
Cohort: May 2026 (Launch month)
LTV at 30 days: $12 (1 order × $60 AOV)
LTV at 90 days: $45 (1.5 orders × $60 AOV)
LTV at 180 days: $85 (2 orders × $60 AOV)

Cohort: June 2026
LTV at 30 days: $15
LTV at 90 days: $52
[etc.]
```

## Part 6: Retention & Growth Loop

### Day 1 Experience (Critical)

**Goal:** User opens app, immediately finds value

```
Onboarding flow:
1. Welcome screen (1 slide, <5 seconds)
2. Permission requests (location, push notifications)
3. Input foot measurements (or quick size estimate)
4. Show shoe recommendations based on size
5. User sees "Here are perfect shoes for you"

Success criteria:
- <2 minutes to first shoe recommendation
- >30% of users proceed to view recommendations
- >10% of users search after onboarding
```

### Day 7 Retention

**Goal:** User becomes a repeating user

**Actions to drive retention:**

```
Push Notifications (24-48 hours after install):
"You added Air Max to wishlist. They're now 20% off!"
or
"New running shoes just dropped. See if they match your size."

Email (Day 3):
"Found your perfect shoe size. Here's $10 off your first purchase."

In-app messaging (Day 5):
"Loving the app? Tell us what you think →"
(Prompt for review)

Community feature:
Show reviews from other users (social proof)
```

### Month 1 Goal: First Purchase

**Incentives to drive first purchase:**

```
Option 1: First-time discount
- 10% off first order
- Sent via push notification
- Creates urgency

Option 2: Free shipping
- More transparent than % discount
- Easier to understand

Option 3: Loyalty program
- Earn 10 points per dollar spent
- 100 points = $10 off
- Encourages repeat purchases

Example campaign:
Day 1: Welcome, input size
Day 2: Push notif - "Found perfect shoes for you"
Day 3: Email - "10% off first purchase (24 hrs)"
Day 4: In-app - "Still deciding? See user reviews"
Day 5: Push notif - "Last chance for 10% off"
```

### Repeat Purchase Loop

**Goal:** User becomes loyal, lifetime customer

**Recurring touchpoints:**

```
Weekly push notifications:
- New arrivals in their size
- Price drops on wishlist items
- Friend activity (social)

Monthly email:
- Your shoe style summary
- Recommended new styles
- Seasonal trends

In-app:
- "Due for new shoes?" reminder
- Trending shoes this week
- Friend reviews

Loyalty rewards:
- Double points on birthday month
- VIP early access to drops
- Exclusive discounts
```

## Part 9: Retention & Support

### Support Excellence = Growth

**Why support matters for growth:**

```
Supportive brand → Happy users
Happy users → Great reviews
Great reviews → Better app store ranking
Better ranking → More downloads
More downloads → Sustainable growth
```

**Support metrics to track:**

```
Response time:
- Target: <2 hours for critical issues
- Measure: Time from user message to first response
- Good: <1 hour average

Resolution rate:
- Target: 80% resolved on first interaction
- Measure: % of issues resolved without escalation
- Track: Common issues that need escalation

Satisfaction:
- Target: >4.0/5.0 rating on support
- Measure: Post-support survey (1-5 scale)
- Follow up: On any <4 rating

Repeat issues:
- Track: Issues reported multiple times
- Action: Fix root cause, prevent recurrence
```

### Community Building

**Active communities drive retention:**

```
Forums/discussion board:
- Tip: "Best shoes for wide feet"
- Discussion: Nike vs Adidas sizing
- Moderation: Keep conversations positive

Social media presence:
- Respond to all mentions (Twitter, Instagram, TikTok)
- Engage with user content
- Share community wins

Events & partnerships:
- Virtual events (Q&A with shoe expert)
- Meetups (in major cities)
- Collaborations with influencers
```
